# Archi-Flow — Architecture Simulator

Interactive drag-and-drop architecture visualization with real-time traffic simulation. Modeled after draw.io / Lucidchart — professional, fast, zero-install, runs in the browser.

**Live:** https://archi-flow.onrender.com

---

## Quick Start

```bash
npm install
npm start          # dev server at http://localhost:3456
```

## Build for Production

```bash
npm run build      # minifies CSS/JS → dist/
```

The server (`server.mjs`) always serves from `dist/`. After editing any source file in `src/`, run `npm run build` before testing.

## Tech Stack

- **Pure HTML + vanilla JS** — no framework, no build-time transpilation needed for dev
- **Node.js static server** — `server.mjs` serves `dist/` on port 3456
- **Supabase** — cloud auth + diagram storage (optional; set `SUPABASE_URL` and `SUPABASE_ANON_KEY`)
- **No external JS dependencies at runtime**

## Key Files

| File | Purpose |
|------|---------|
| `src/app.js` | Main app — canvas, simulation, PDF export, all UI logic |
| `src/app.css` | All styles, responsive breakpoints |
| `src/components.js` | 39 component definitions |
| `src/examples.js` | 8 example diagram templates |
| `src/rules.js` | Architecture connection validation rules |
| `index.html` | App shell and toolbar HTML |
| `server.mjs` | Static Node.js server (serves `dist/`) |
| `dist/` | Built files — gitignored, auto-generated by `npm run build` |
| `.claude/PLAN.md` | Full feature roadmap and iteration status |

## Environment Variables

| Variable | Purpose | Required |
|----------|---------|----------|
| `SUPABASE_URL` | Supabase project URL | No (cloud features disabled without it) |
| `SUPABASE_ANON_KEY` | Supabase anon/public key | No |
| `SIGNALING_URL` | WebSocket signaling for collab | No |
| `PORT` | Server port (default: 3456) | No |

Set these in a `.env` file or in your hosting provider's environment settings.

## Deployment

Auto-deploys from the `release/serverside` branch to Render. The `render.yaml` configures the Node.js service. Ensure env vars are set in the Render dashboard.

## Testing

```bash
npm test                # unit/smoke tests
npm run test:browser    # Playwright browser smoke test
```

## Features

- Drag-and-drop canvas with 39 architecture components
- Real-time BFS traffic simulation with load%, latency, P95, error rate
- Auto-scaler, load balancer, read replicas
- Cost HUD with reserved pricing toggle
- Professional PDF report export
- Shareable `#arch=` URL state
- Cloud auto-save + My Flows gallery (SVG previews, tags, shared-with-me)
- Dark/light theme, minimap, undo/redo, keyboard shortcuts
- One-click topology fix suggestions
